## 设计理念

大多数投资分析对管理层的评估停留在表面：履历、持股比例、薪酬。人品、自我反思、学习和纠错可以领先于季报被观察到：已经实施的决策、组织和激励改变，不必等利润数字出来才允许记录。利润后来是否出现，是复核，不是这条证据的成立条件。

这类证据仍然只是研究里的一个维度，和生意质量、护城河、风险、估值并列。管理层判断好，不使任意价格变得安全。

本 Skill 是 `/investment-research` 第五步管理层评估的深化版。标准研究、清单、财报更新和持有期跟踪不重复定义另一套分数；它们使用下面三节，材料不足就转到本 Skill，事件 ID 保持连续。

AI 无法和管理层吃饭。公开信息能做的是：

- 把原话、当时信息和后来的行为记成可复核的事件，区分承诺、预测和愿景
- 看困难时期怎么待人、怎么归因、有没有改组织而不只改措辞
- 逐笔看资本配置，以及稀释、回购、关联交易是否站在股东一边
- 用员工、客户、供应商的可核对反馈做侧面验证，并标明可信度

口才、创始人身份、持股或控制权本身，都不是「伟大管理层」的证据。失败、撤回和含糊其辞必须与后来看对的决定一起记录。

## 管理层证据记录

先记事件，再打分。每条独立事件用下表。没有材料就留空并标「未知」。不要只收集成功案例，不要用事后结果改写当初的原话。

| 字段 | 要求 |
|------|------|
| 事件ID | 稳定编号，如 `M-001`。后文判断和估值调整只引用 ID |
| 日期 | 原话或决策的发生日。复核日另写 |
| 表述与来源 | 摘录原话，写直接来源的标题和日期。第三方转述必须标「转述」，不得写成原话 |
| 当时信息 | 只写说话或决策时已经公开、或有证据表明管理层当时掌握的信息。不用事后结果倒推「他们当时一定知道」 |
| 类别 | 承诺 / 预测 / 愿景，只取其一。没有期限和可核对对象的愿景，不算未兑现的承诺 |
| 承认的问题 | 承认了什么。没承认写「未承认」 |
| 归因 | 内部 / 外部 / 混合 / 未知。归因外部本身不是不诚信 |
| 改变 | 具体的决策、组织或激励变化。只改措辞不算改变 |
| 实施状态 | 已实施 / 计划 / 未知。二者必须分开 |
| 代价 | 已经付出的成本、机会或人员损失。代价不等于决策正确 |
| 反证 | 与当前解释相反的事实。还没找写「尚未找到」，不要写成「没有反证所以成立」 |
| 复核 | 计划复核日、到期日，以及后来的结果。未到期写「未到期」 |
| 证据可信度 | 高：可核对的一手原文。中：一手但残缺，或两个独立转述一致。低：单一转述、营销稿、无法回溯。低可信度不得单独支持否决或加分 |
| 归责 | 可归责 / 未到期 / 不可归责 / 未知。后三项不是 0 分，也不是通过 |

学习有没有沉淀进组织，每条事件另写一句：改变停在个人发言，还是已经进入流程、人事权、激励或资本开支的常规。只存在于发言里的反思，成熟度停在口头。

### 虚构示例

下例只演示字段。公司、人物、数字和出处都是虚构的，禁止抄进真实公司报告。

| 字段 | 示例 |
|------|------|
| 事件ID | M-示例-001 |
| 日期 | 2022-03-01 原话；2024-03-01 复核 |
| 表述与来源 | 原话：「明年把北区店缩到 20 家。」直接来源：虚构《甲公司 2022 年 3 月股东会纪要》第 4 页。不是转述 |
| 当时信息 | 纪要写明北区连续四季店均现金流为负。当时还没有 2023 年的闭店结果 |
| 类别 | 承诺 |
| 承认的问题 | 承认北区选址错误 |
| 归因 | 内部 |
| 改变 | 取消北区拓展编制，店长奖金改为单店现金流 |
| 实施状态 | 已实施：2022 年内编制已取消。计划：剩余门店出售，当时尚未签约 |
| 代价 | 当年确认闭店费用。费用发生不等于收缩是对的 |
| 反证 | 虚构的 2023 年行业资料显示北区需求回升，留下的两家店利润转正。这削弱「北区整体不该存在」，但不改写 2022 年原话 |
| 复核 | 2024-03-01：仍有 28 家，没有到 20 家。原承诺不改口径 |
| 证据可信度 | 高（虚构的一手纪要） |
| 归责 | 可归责于没有做完。不得因此直接写成不诚信；是否隐瞒，要另找证据 |

## 四项判断与诚信门槛

四项分开写。每项的 1–5 分是主观研究纪律，用来强迫写清证据，不是统计验证过的人格分数，也不是回报模型。缺证据写「未知」。未知不代入 1 分，也不代入 5 分。

| 判断 | 在看什么 | 不在看什么 |
|------|----------|------------|
| 诚信与待人 | 已核实的虚假陈述、隐瞒，以及对股东、员工、客户、供应商或监管的损害 | 预测不准、语气、创始人身份 |
| 学习与纠错 | 有没有可复核的诊断，改变有没有留在组织里 | 单次成功、口才、利润是否已经兑现 |
| 资本配置 | 并购、再投资、回购、分红、退出和止损 | 持股比例本身 |
| 股东利益与治理 | 稀释、回购、薪酬、投票权、关联交易是否按股东利益运行 | 把控制权写成「会为股东着想」 |

战略眼光和执行过程仍要写进证据。它们不再单独占一个可以和诚信相加的权重：预测准不准归入学习与纠错，钱投得怎么样归入资本配置。

### 学习证据成熟度

成熟度只说明证据走到哪一步。它不是线性晋级，可以停住，也可以退回。成熟度不等于方向有利，也不等于成功概率。

| 阶段 | 含义 |
|------|------|
| 未知 | 没有可归类的材料，或未到期、不可归责 |
| 口头反思 | 承认问题，但没有具体诊断 |
| 具体诊断 | 说清原因、范围和可核对的对象 |
| 已执行改变 | 决策、组织或激励已经实施，可以先于财报记录 |
| 跨事件复核 | 同类改变在不同事件或不同周期再次被核对，并且能看出留在组织里还是只留在个人 |

方向另写：有利 / 不利 / 尚不明确。已经执行的错误改变仍是「已执行改变」，方向写不利。一次复盘不能升到跨事件复核。

### 诚信门槛先于任何平均

先写门槛，再决定其他分数能不能进入可投讨论。

| 门槛 | 何时使用 | 后果 |
|------|----------|------|
| 不可投 | 重大问题已经核实：一手文件，或处罚、裁决、公司更正、足以支持的内部记录 | 退出可投范围。其他三项可以继续记录，但能力高分、治理结构或便宜价格都不能抵消。不得提高折现率，把标的留在可投范围 |
| 未证实 | 只有传闻、单一低可信转述，或调查没有结论 | 不自动定罪，也不自动放行。写明缺哪份证据，以及复核日 |
| 未知 | 没有足够材料，或事件未到期、不可归责 | 不通过，也不否决。相关估值假设维持原状 |
| 可研究 | 已经查找，且没有已核实的重大诚信问题 | 可以继续讨论另外三项和估值。这不是品格证明 |

承诺和预测的兑现可以计数，计数不是诚信分。兑现率低，可能是预测差或执行差，先归入学习与纠错或资本配置；只有另有已核实的虚假或隐瞒，才进入诚信。用过于保守的承诺把命中率做高，同样不是诚信。不要把命中率分成「高于 80% 为优秀、60%–80% 为合格、40%–60% 为担忧、低于 40% 为不可信赖」这种诚信档。

旧稿曾把诚信 35%、战略与执行 25%、资本配置 25%、治理 15% 加权。这和一票否决冲突：诚信 1 分、其余三项 5 分时，加权仍约为 3.6 分。这个加权不再计算，也不再作为结论。四项分数并列。需要兼容旧表的单列时，只填门槛：不可投 / 未证实 / 未知 / 可研究。

下面三个问题仍要回答，禁止合成一个星级：

1. 是否正直：只按诚信门槛回答。未知就写未知。
2. 是否有能力：学习与纠错、资本配置分开写，不合并成一个能力分。
3. 是否愿意把钱交给此人十年：这是研究者的主观结论。门槛为不可投或未知时，不得回答「愿意」。

## 估值衔接

管理层证据要改变估值，必须走完这条链，缺一环就维持原假设：

管理层证据（事件 ID） → 可解释的经营机制 → 某一个情景或参数 → 股东现金与每股价值

| 证据改变的是 | 可以进入的参数 | 不允许的写法 |
|--------------|----------------|--------------|
| 学习是否留在组织 | 优势持续期、优势衰减、修复情景 | 把成熟度直接写成「再高增长五年」 |
| 资本配置 | 增量 ROIC、再投资额、项目损失与退出 | 用「善于配置」同时提高增长和终值 |
| 股东利益与治理 | 稀释、回购、关联交易造成的治理损失 | 把持股比例加成估值溢价 |
| 诚信门槛 | 可投还是不可投 | 用更高的折现率补偿已核实的重大诚信问题 |

每一次偏离原假设，写一行。没有偏离就写一行「维持原假设」：

| 证据ID | 原假设 | 新假设 | 机制 | 适用情景 | 置信度与反证 | 与其他渠道是否重叠 |
|--------|--------|--------|------|----------|----------------|--------------------|

未知、未到期、不可归责，都写维持原假设。不得为了填表新造情景概率。概率若出现，必须写明是研究者的主观判断，并附反证；它不是由管理层分数算出来的。

同一条优势不得同时上调增长、上调终值、下调折现率，再加一笔溢价。若认为几个渠道彼此独立，写出不重叠的部分，并说明拿掉其中一条时每股价值怎么变。好的管理层证据也可以导出更少的再投入、更慢的增长和更低的估值。

没有这张表时，估值工具的输出只代表原来的财务假设。本 Skill 不新跑一套折现；要算数时，仍用研究者写明的参数调用既有工具。

## 执行流程

### 第一步：识别关键管理层并启动并行数据收集

使用 WebSearch 确认以下关键人物：

| 角色 | 姓名 | 任期 | 背景 | 持股/期权 |
|------|------|------|------|----------|
| CEO/董事长 | | | | |
| CFO | | | | |
| 创始人（如不在位） | | | | |
| 实际控制人（如不同于CEO） | | | | |
| 其他关键高管 | | | | |

**注意**：区分「谁在做决策」和「谁的名字在头衔上」。有些公司创始人虽然卸任但仍是灵魂人物（如黄峥之于拼多多）。持股和头衔只填这张表，不直接转化为分数。

确认关键人物后，使用 Task 工具启动多个后台 Agent **并行**收集以下数据。收集结果先落入「管理层证据记录」，再进入后面的判断：

1. Agent 1：CEO 公开发言与预测记录（股东信、电话会、采访、社交媒体），保留原话和出处
2. Agent 2：资本配置决策记录（并购、回购、分红、新业务投资）
3. Agent 3：治理结构与薪酬（股权结构、关联交易、高管薪酬）
4. Agent 4：侧面验证信息（员工评价、客户反馈、行业口碑），区分一手与转述

### 第二步：能力与学习记录

#### 2.1 判断记录

搜索 CEO 过去 5 年的公开发言，提取判断。预测准不准写入学习与纠错，不写入诚信，除非另有已核实的虚假陈述。

| 时间 | 原话 | 类别 | 当时信息 | 后来的结果 | 是否改口 |
|------|------|------|----------|------------|----------|
| | | 承诺/预测/愿景 | | 未到期则写未到期 | 原话保留 |

#### 2.2 纠错与组织

| 维度 | 评估 | 证据ID |
|------|------|--------|
| 说了的事是否做成 | | |
| 诊断是否具体 | | |
| 改变是否已实施，还是仍是计划 | | |
| 改变是否进入组织常规 | | |
| 成熟度阶段 | 未知 / 口头反思 / 具体诊断 / 已执行改变 / 跨事件复核 | |
| 方向 | 有利 / 不利 / 尚不明确 | |

成熟度可以低于上一次研究。已执行改变不因利润尚未体现而删掉。

### 第三步：诚信与待人

**巴菲特**：「我们寻找三种品质：正直、智慧和精力。如果没有第一种，后两种会害死你。」

#### 3.1 话与做：先分类，再决定是不是诚信问题

从过去的财报电话会、股东信、公开采访提取具体表述，每条写入证据记录。

| 事件ID | 时间 | 原话 | 类别 | 归责 | 是否另有虚假或隐瞒的证据 |
|--------|------|------|------|------|--------------------------|
| | | | 承诺/预测/愿景 | 可归责/未到期/不可归责/未知 | 无 / 未证实 / 已核实 |

可以报告可归责事项里的兑现次数，但必须同时报告未到期和不可归责的条数，这两类不进分母后冒充失败，也不进分子冒充通过。这个计数不转换成诚信档位。

#### 3.2 困难时期的表现

搜索重大危机（股价暴跌、业绩不及预期、监管冲击、竞争加剧）：

| 事件ID | 危机 | 时间 | 怎么待人 | 归因 | 事后是否改组织 | 可信度 |
|--------|------|------|----------|------|----------------|--------|

关注：主动说明还是躲避；归因内部还是外部；做的是困难的事，还是短期安抚。困难时期的表现可以同时影响诚信与待人、学习与纠错，但一条证据在两个判断里都引用时，后文估值衔接要避免重复计价。

#### 3.3 对利益相关方的态度

| 利益相关方 | 已核实行为 | 证据ID | 可信度 |
|------------|------------|--------|--------|
| 股东 | | | |
| 员工 | | | |
| 客户/用户 | | | |
| 商家/供应商 | | | |
| 监管/社会 | | | |

没有证据的格子写未知。媒体形容词不填进「已核实行为」。

### 第四步：资本配置能力

这一节只填「资本配置」这一项。它回答每赚到的钱后来变成了什么，不回答这个人是否诚信。

#### 4.1 资本配置决策记录

搜索过去 5 年的重大资本配置，逐笔进入证据记录。

**并购：**

| 事件ID | 时间 | 标的 | 金额 | 当时说的逻辑 | 事后回报 | 是否已退出 | 1-5 |
|--------|------|------|------|--------------|----------|------------|-----|

**回购：**

使用 `tools/financial_rigor.py verify-valuation` 校验回购时和当前的估值倍数。工具只验算倍数，不判断回购是否高明。

| 事件ID | 时间 | 金额 | 平均价格 | 当时倍数 | 事后回看 | 1-5 |
|--------|------|------|----------|----------|----------|-----|

**分红：**

| 年份 | 分红 | 分红率 | 同期自由现金流 | 是否可持续 | 证据 |
|------|------|--------|----------------|------------|------|

**再投资与退出：**

| 事件ID | 时间 | 领域 | 累计投入 | 已实施还是计划 | 损失或退出 | 1-5 |
|--------|------|------|----------|----------------|------------|-----|

### 第八步：输出管理层评估报告

#### 报告必须包含

```
一、关键人物（职务与持股只作事实）
```

| 资本配置 | — | | | |

门槛为不可投时，结论就是不可投。表内其他高分保留为记录，不参与「还能不能投」。

## 关键原则

- **诚信门槛先于分数** — 已核实的重大问题不能用能力高分抵消；传闻和未知也不自动定罪
- **兑现率不是诚信** — 说得保守而命中率高，同样不是诚信
- **原话不改口径** — 复核只追加结果，不重写当初的预测
- **未知保持未知** — 未到期、不可归责、没有材料，都不是 0 分或通过
- **代价不是正确** — 付了代价只说明发生过，不说明决策对
- **组织比口才重要** — 看改变有没有进入流程和激励
- **估值要有机制** — 证据只通过写明的参数影响每股价值；好管理层也可以对应更慢的增长
- **不爱上管理层** — 欣赏某个人，仍然要写反证
